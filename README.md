# Dependency Graph Visualizer (Variant 25)

## Общее описание
CLI-приложение для получения и анализа графа зависимостей пакетов.
Текущий этап: построение графа зависимостей транзитивности (DFS без рекурсии), 
обработка циклов, фильтрация по максимальной глубине и поддержка режима 
тестирования (чтение из локального файла).
